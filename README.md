# WIP-Custom-Silksong-Skin-Tool
A tool specifically made for artists working on Hollow Knight: Silksong custom skins. It automatically accepts custom heads shapes from an artist and uses an automated system to paste the created heads across all (supported) hornet sprites.

Names suggestions would be highly appreciated!

## About
I have been interested in making tools for skin creation for a long time, even though I cannot draw to save my life. After researching I found that there were no tools yet created that automated part of the process, aside from Custom Knight, Custom Knight Creator, and tools that change Hornet's cloak color. While looking through the sprite sheets and animations (thanks Custom Knight!) I found that many head shapes are copied from sprite to sprite.

I thought it might be helpful if the process could be automated, potentially shaving hours off of skin making, and also opening up skin creation to less experienced artists or those with less time.

## Implementation
The process would go as follows:

1. Draw your custom head shapes using the references provided.
Feel free to get as creative as you want, as long as the bottom of the head is similar. This matters more so with direct pastes because of overlaps between her head/cloak.
